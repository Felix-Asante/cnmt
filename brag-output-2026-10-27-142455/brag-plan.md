# Brag Plan: C.N.M.T — Trust Loop (9/10 pass)

## What is this app?
C.N.M.T’s customer remittance app lets people send money abroad with clear rates, a transferable reference, payment-proof verification before payout, status tracking, and cancel-before-pay control.

## The angle
“Money that moves with proof — clear rates in, verified payout out.”
First-time-sender demo film: teach the trust loop. Cancel is an alternate unpaid path (control), never a rewind after Delivered.

## Hook (first 2-3 seconds)
Product chrome in-frame immediately: miniature transfer summary strip (You send £250 / They get GH₵…) + TRANS-UK-GH-4821 peek under **MONEY THAT MOVES / WITH PROOF**. Eyebrow `C.N.M.T`. Sub settles: Clear rates in. Verified payout out.

## Key moments (the middle)
- Live quote card: You send £250 · They get GH₵4,850 · Fees included · Promo SAVE10 → pay £225
- Navy pay panel + Barclays select + upload proof (“Verified before payout”)
- Track timeline lights Request → Payment → **Verification** (Delivered whisper only)
- Cancel unpaid confirm → Cancelled (calm control)

## Outro / punchline
Full-bleed brand lockup: CN glyph + **C.N.M.T**, “International money transfer for everyone”, “You’re in control before you pay.”, big **Send money →**, support chip. Frame feels as dense as mid-film UI.

## User flow worth showing
1. Send request (corridor → quote → recipient/promo → TRANS- + Copy)
2. Pay + upload proof
3. Track to Verification
4. Cancel unpaid (parallel trust beat)

## Tone
- Preset: polished
- Creative direction: finance-product demo film for first-time senders (9/10 retention pass)
- Interpretation: soft crossfades; one job per beat; simulated taps; brand red sparingly; no jokes; no SaaS filler.

## Duration: 25 seconds (primary) + 14 seconds (social cutdown)
