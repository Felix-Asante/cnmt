**Brand:** C.N.M.T  
**Channel focus:** WhatsApp (Status, chat, broadcast)  
**Support:** +212 715 617 637 · +212 627 140 999 · support@cnmt.shop

This kit is built so a sole proprietor can post and reply without redesigning anything. Open folders on your phone or laptop and send.

---

## Day 0 — Setup (30 minutes)

1. **Profile**
   - Set `profile/whatsapp-avatar.jpg` as WhatsApp Business photo
   - Set `profile/whatsapp-banner.jpg` as cover (Business app)
   - Paste About text from `copy/bio-and-links.txt`

2. **Star / pin templates**
   - Open `copy/whatsapp-templates-en.txt` (and FR if needed)
   - Star the Welcome + How it works + Payment reminder messages in WhatsApp (or keep the file on your phone)

3. **QR**
   - Save `qr/whatsapp-qr-poster.jpg` to camera roll
   - Print `qr/whatsapp-qr-print.png` or `print/a6-flyer-counter.jpg` for the counter
   - Print `print/business-card.jpg` if you hand cards out

4. **Website / chat link**
   - Use the click-to-chat URL in `LINKS.txt` anywhere people find you

## Rules that protect trust

- Never invent fees or rates in graphics — use live quotes in chat.
- Promo reduces **what they pay** (principal), not a mysterious fee cut — keep that clear.
- Cancel = **unpaid only** — say “before you pay,” never “we reverse paid transfers” in marketing.
- Always ask for / show the **TRANS-** reference when helping.
- Fictional demo amounts in films (£250 / GH₵…) are examples only.
